# pochemu-kuda-zachem-info
Информационный хаб проекта «Почему? Куда? Зачем?» - веб-адаптации интеллектуальной викторины в эстетике ТВ 90-х по мотивам «Что? Где? Когда?». Здесь собрана документация: правила раундов, архитектура, описание и материалы разработки. Подробные ответы для любопытствующих знатоков, зрителей и контрибьюторов клуба.
